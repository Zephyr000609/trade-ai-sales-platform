# 第一阶段产品需求

## 目标

为 2–3 名外贸业务员提供可实际使用的 Web 工作台，在收到询盘后 3 小时内生成可审核的英文回复草稿。

## 用户与数据边界

- 每名业务员使用独立账号、邮箱和客户池。
- 第一阶段不设管理员角色。
- 所有业务数据必须带有 `organization_id`、`user_id`、`mailbox_id`。
- 第一阶段只生成草稿，禁止自动发送。
- 公开仓库不得存放真实邮件、客户资料、价格表、产品机密或凭据。

## 新客户流程

1. 读取新邮件、完整往来线程和附件。
2. 识别公司、联系人、国家、行业和需求。
3. 根据行业、公司规模和预计年用量评为高/中/低。
4. 提取全部技术要求并统一单位。
5. 缺少关键参数时生成补充问题。
6. 判断风机类型和 AC/DC/EC 电机类型。
7. 按电压、风量、压力、尺寸及客户明确要求执行硬条件过滤。
8. 对合格型号排序并展示证据。
9. 生成客户要求与产品参数对比表。
10. 匹配标准价格；运费未知时留空。
11. 生成英文邮件草稿并再次校验关键参数。
12. 同步网易邮箱草稿箱并提醒业务员。

## 老客户流程

识别客户及历史线程，并判断当前状态：

- 技术方案沟通
- 等待客户确认
- 报价与议价
- 订单或 PI
- 生产进度
- 交期
- 发货与物流
- 到货
- 售后
- 复购

订单号、交期、物流单号等资料缺失时，系统创建待补充窗口；业务员补充后自动恢复处理。

## 文件与知识库

第一阶段支持：

- PDF
- Word
- Excel
- 图片
- 邮件附件
- 扫描版 PDF 和图片 OCR

视频仅保存标题、说明和人工文字稿，完整视频理解放入后续版本。

## 行业规则示例

### AHU

风量、压力、电压、尺寸、主动式 PFC、UL 认证。

### 家用小家电

风量、压力、电压、尺寸、噪音。

### 铁路

温度范围、尺寸公差、耐压测试、绝缘电阻及客户明确提出的其他要求。

## 价格

- 使用标准价格表。
- 大部分客户采用标准价格。
- 运费未知时不得编造。
- 第一阶段不自动生成正式报价单和 PI。

## 通知

- 应用内待审核数量与任务状态。
- 企业钉钉通知。
- 接近 3 小时处理期限时升级提醒。

## 第一阶段不包含

- 自动寻找潜在客户
- 批量开发信
- 完整 CRM
- 报价单或 PI 自动生成
- 完整视频理解
- 在线收费
- 对外开放注册
- 完整管理员后台
