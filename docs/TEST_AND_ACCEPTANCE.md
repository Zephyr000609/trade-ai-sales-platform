# 测试与验收

## 上线门槛

- 95% 的新邮件在 3 小时内生成草稿或进入待补充状态。
- 新老客户及业务分类准确率不低于 95%。
- 最终盲测集中的关键参数零错误。
- 不符合硬条件的产品不得进入推荐候选。
- 正确型号进入 Top 3 的比例不低于 90%。
- 80% 以上英文草稿经少量修改即可发送。
- 标准价格匹配零错误。
- 草稿同步成功率不低于 98%。
- 邮件、附件、客户和草稿不得跨业务员串线。
- 系统连续真实试运行至少 5 个工作日。

## 历史案例集

每个案例应包含：

- 原始邮件和允许使用的附件
- 正确的新老客户分类
- 正确业务状态
- 应补问的问题
- 正确选型和候选型号
- 客户要求与产品参数对比
- 标准价格
- 最终发送的英文回复

真实案例不得进入公开仓库。公开仓库只能保存脱敏后的合成样例。

## 必测场景

- AHU
- 家用小家电
- 铁路
- 参数完整
- 参数缺失
- 参数相互冲突
- 不同单位换算
- 扫描 PDF
- 表格附件
- 老客户技术沟通
- 老客户交期询问
- 老客户物流询问
- 售后和复购

## 关键参数规则

关键参数包括：

- 风量
- 压力
- 电压
- 风机尺寸
- 客户明确提出的任何参数

关键参数测试采用零容忍。出现错误时必须阻止发布，并补充回归测试。

## 安全测试

- 业务员 A 不得访问业务员 B 的邮箱、附件、客户或草稿。
- 过期会话必须失效。
- 邮箱授权码和模型 API Key 不得出现在日志。
- 文件下载必须进行权限检查。
- 后台任务不得绕过租户过滤。
- 公开错误信息不得包含客户邮件正文。
