# Trade AI Sales Platform

面向外贸企业的 AI 邮件、产品知识库、技术选型与客户跟进平台。

## 当前目标

在第一阶段构建可供公司内部使用的 Web MVP：

- 多业务员独立登录与数据隔离
- 网易邮箱 IMAP 接入及草稿箱同步
- PDF、Word、Excel、图片及扫描件 OCR
- 产品资料 RAG 知识库与结构化产品参数库
- 新老客户识别与邮件业务状态判断
- 新客户基础背调及高/中/低价值分级
- 技术要求提取、硬条件筛选与产品推荐
- 客户要求与产品参数对比表
- 标准价格匹配与英文邮件草稿
- 信息不足时请求业务员补充并自动恢复处理
- 应用内与企业钉钉提醒

## 核心原则

1. 关键技术参数不得由模型自由编造。
2. 产品选型采用“结构化硬筛选 + AI 辅助排序”。
3. 参数、价格和结论必须能够追溯到数据来源。
4. 不确定、冲突或资料不足时转人工补充。
5. 第一阶段只生成草稿，不自动发送邮件。
6. 从第一天保留 organization_id、user_id 和 mailbox_id，为多租户 SaaS 做准备。

## 路线图

### Phase 1 — 内部 MVP

打通“接收邮件 → 分析 → 选型 → 对比表 → 英文草稿 → 人工审核”的完整闭环。

### Phase 2 — CRM 与主动获客

客户画像、潜在客户搜索、个性化开发信、邮件序列、销售阶段和长期跟进。

### Phase 3 — 商业化 SaaS

企业租户、管理员权限、严格数据隔离、用量计费、审计、客户支持和商业化运营后台。

## 验收基线

- 95% 的新邮件在 3 小时内生成草稿或进入待补充状态
- 新老客户及业务分类准确率不低于 95%
- 最终盲测集中的关键参数零错误
- 正确型号进入 Top 3 的比例不低于 90%
- 80% 以上英文草稿经少量修改即可发送
- 不满足硬条件的产品不得进入推荐结果

## 安全说明

本仓库为公开仓库，不得提交以下内容：

- 邮箱授权码、密码、API Key 或其他凭据
- 真实客户邮件、联系人和商业信息
- 非公开价格表
- 产品机密资料或受限制文件
- 生产数据库和真实日志

真实业务数据必须存放在受控的私有环境中，并进行加密和权限隔离。
